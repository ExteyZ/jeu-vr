Bac à sable physique

Dans le casque : appuie sur « ENTER VR » en bas de l'écran.
Sur PC : clique dans la scène, puis ZQSD pour marcher, souris pour regarder, Espace pour sauter, Maj pour courir. Clic gauche / droit : attraper avec la main droite / gauche. Molette : avancer les mains. R : tout remettre en place.
