Chargement du Complexe Delta…

Complexe Delta

Dans le casque : appuie sur « ENTER VR » en bas de l'écran.
Graphismes Ultra : branche le casque au PC (Quest Link), ouvre cette page dans Chrome ou Edge sur le PC, puis « ENTER VR » : c'est la carte graphique du PC qui dessine.
Sur PC : clique dans la scène, puis ZQSD pour marcher, souris pour regarder, Espace pour sauter, Maj pour courir, C pour s'accroupir. Clic gauche / droit : attraper avec la main droite / gauche. E / A : gâchette de la main droite / gauche (utiliser l'objet, lancer le pouvoir, cliquer sur le panneau). I : inventaire, P : super-pouvoirs, O : options, B : pouvoir activé / coupé. Molette : avancer les mains. R : tout remettre en place. X : revenir au hall.
